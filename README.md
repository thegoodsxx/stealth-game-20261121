NIGHTWATCH: Silent Wing, a top-down 2D stealth game on an HTML canvas — cross a night-time archive facility unseen, slip past patrolling guards with occluded vision cones, collect 3 intel folders, reach the glowing exit vault door. Keyboard only (WASD/arrows, Shift to sneak, P/Esc pause, R restart). Synthesized WebAudio sound, no external assets.

## Run it

```sh
python3 -m http.server --directory game 8000
# Open http://localhost:8000
```
